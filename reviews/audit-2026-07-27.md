## 一、发布阻断项(P0)

### 🔴 P0-1 应用锁可被"取消生物识别"直接绕过 ✔已验证

`biometric_auth.dart:56-64` 用 catch-all 把所有异常归为 `unavailable`;而 local_auth 3.x 对**用户取消**正是抛异常(已核对 `local_auth_android:48-52`、`local_auth_darwin:66,90`)。`app_lock_gate.dart:109-115` 在 `unavailable` 且未设 PIN 时 → `unlocked`。

默认配置即命中(应用锁开 + 生物识别 + 新钱包无 PIN):**拿到已解锁手机 → 点 Face ID → 点取消 → 直接进入钱包**,可查看余额、发起转账、进入助记词导出。

> 修:区分异常类型(取消/超时/锁定 → `failure`;无硬件/未录入 → `unavailable`);`unavailable` 且无 PIN 时**强制引导录入 PIN**,删除 fail-open 分支。

### 🔴 P0-2 认证失败时展示硬编码假助记词 ✔已验证

`wallet_screens.dart:1581-1584`:`on CoreCryptoException → words = _mnemonic`(演示词 `walnut breeze copper…`)。认证取消/失败/锁定全继承该异常。

更严重的是同一常量还在**真实备份流程**上:`wallet_screens.dart:34-37`,首页备份横幅 → `/create-warn` → `/mnemonic-show` 这条路径 `pendingMnemonic` 为 null,于是**真实热钱包持有者被展示假助记词、被就假词答题、然后 `markBackedUp()` 触发"备份已验证"**。资金从此不可恢复,而 app 声称已备份。

> 修:删除 `_mnemonic`;`_activeMnemonic` 为 null 时拒绝渲染;认证异常向上冒泡为错误态。

### 🔴 P0-3 逗号被当作千分位剥离 → 10 倍超额转账 ✔可执行验证

```
Amount.parse('1,5', 18) → 15000000000000000000   // 15 ETH,而非 1.5 ETH
```
`amount.dart:24,29` 无条件 `replaceAll(RegExp(r'[_,\s]'), '')`。输入框(`transfer_screens.dart:835`)**无 inputFormatters**。德/法/西/葡语区数字键盘的小数键就是 `,`——用户想转 1.5,签出 15,余额充足时校验全部通过、零提示。

> 修:`Amount.parse` 对逗号抛 `AmountError`(或按 locale 显式转换);输入框加 `FilteringTextInputFormatter`。

### 🔴 P0-4 ERC-20 收款地址绕过 EIP-55 校验 ✔可执行验证

```
Addresses.validate(flipped) = false     // 校验器正确拒绝
Erc20.transferCalldata(to: flipped)     // 却接受,产出 68 字节 calldata
```
`evm_abi.dart:17-24` 只做长度检查,不调 `Addresses.validate`;`evm_tx.dart:81` 的 token 分支直接传入(原生转账走 `addressBytes` 有校验,**只有代币这条路没有**)。一个字符打错的地址 → 代币打到无人持有私钥的地址,永久损失。

> 修:`Erc20.transferCalldata` 内部先校验,与 `Trc20`/`SolanaMessage` 的既有做法对齐。

### 🔴 P0-5 配对钱包的转账页预填真实 USDT 合约地址

`transfer_screens.dart:429-432` 预填 `TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t`(**TRON 主网 USDT 合约本体**,校验和有效)+ 金额 `120.00`。清空条件是 `hasExpandedEvm`,而 `pairing_airgap.dart:70-83` 只填四链地址 → 配对钱包恒为 false → **输入框永不清空**。用户配对冷签名器后进"发送",一路点下去即向合约地址转 120 USDT,资金烧毁。

### 🔴 P0-6 交易表无网络维度 → 跨网络加速可签出真实主网交易

`tables.dart:100-133` 只有 `coin`,无 chainId/networkId。`transfer_screens.dart:2347-2390` 加速/取消时用**当前激活网络**,nonce/收款人/金额取自旧行。在 Sepolia 发 pending → 切回主网 → 点"加速" → 构造 `chainId=1` 的**真实主网交易**并广播。附带:nonce 冲突检查跨网络误报,会阻塞合法主网转账。

### 🔴 P0-7 确认页展示编造的手续费与 1:1 美元锚

`airgap_codec.dart:70-86` 是静态 demo 费率表,却被**实时** draft 调用(`transfer_screens.dart:1099-1112`);真实 gas 来自 `ChainParamsService` 但从不显示。`:1103` 写死 `≈ $金额` → 0.5 ETH 显示 "≈ $0.5"(错 4 个数量级)。`/fee` 页(`:940`)是硬编码 TRON 档位却服务所有链。**用户批准的不是他将支付的。**

### 🔴 P0-8 Gateway 模式永远访问主网

`gateway_client.dart` 四个方法**都不发送 `network` 参数**,Go 侧 `networks.go:48-51` 缺省解析为 mainnet。后果:Sepolia 会话显示主网余额、用**主网 nonce** 构造 Sepolia 交易、把 Sepolia 签名交易投到主网节点被拒后按 INV-15 **不再回退**——合法交易彻底失败。

### 🔴 P0-9 release 版 Android 缺 INTERNET 权限 ✔已验证

`apps/kt_wallet/android/app/src/main/AndroidManifest.xml:4-6` 只有 `USE_BIOMETRIC`/`DETECT_SCREEN_CAPTURE`/`ACCESS_NETWORK_STATE`;`INTERNET` **只在 debug/profile manifest 里**。开发期永远发现不了,第一个 release APK 装机即余额/价格/gas/广播全部 `SocketException`。

### 🔴 P0-10 CI 依赖防火墙当前失败,气隙防线已停止保护 ✔已验证

```
$ dart run tool/check_deps.dart
check_deps FAIL: cold_signer pubspec has non-whitelisted deps: [...8 项...]
```
白名单是初版遗留(还列着仓库没用的 `qr_flutter`/`sqflite`/`flutter_riverpod`)。CI 会跑这步 → **main 分支 CI 现在是红的**,说明没人在看它的输出。

### 🔴 P0-11 根 lint 配置对全部产品代码无效 ✔已验证

根 `analysis_options.yaml` 开了 `strict-casts`/`avoid_dynamic_calls`/`unawaited_futures`,但 **8 个子包各有一份且都没 `include:` 根文件**,Dart 分析器"最近者胜、不合并"→ 根配置覆盖 0 行产品代码。实证:`main.dart:589-593` 连续三个裸 `Future` 调用,`dart analyze` 报 No issues。对钱包而言 `strict-casts` 正是防金额/地址类型混淆的第一道静态防线。

## 三、中危(P2)摘选

- **PIN 实际不保护密钥**:文档承诺的 `kdfPassword` 双层加密**从未启用**(`EntropyCipher` 是死代码),Signer PIN 只是 UI 闸门;且两平台 KDF 不对等(Android Argon2id vs iOS PBKDF2)。
- **PIN 校验值可迁出设备**:`FlutterSecureStorage()` 未传 iOS/Android options → iOS 默认非 ThisDeviceOnly(进备份可恢复到另一台设备)、Android 默认走旧 RSA 路径(与注释声称的 EncryptedSharedPreferences 不符)。6 位 PIN 的 PBKDF2-100k 离线爆破是分钟级。
- **反重放账本降级静默**:drift 打不开即回退内存实现,重启清空,已拒绝的请求可反复重呈(应 fail closed)。
- **在线钱包的助记词界面不受 FLAG_SECURE 保护**(仅 signer 模式加);用文案劝阻而非系统能力阻止。
- **TRON/Solana 是 native 层盲签**:`WalletCoreBridge.swift:130-160` 零结构校验(EVM 路径相反,有真解析),而注释声称"Wallet Core 会二次严格解析"。
- **MAX 按钮不预留 gas**;`transfer_validation.dart` 里已有正确实现(`maxNative = balance - maxFee`)却是**死代码**,生产完全没用上。
- **Solana 主网 USDC mint 地址无效**(37 字节,合法应为 32);说明该路径从未真正跑通。
- **Solana 地址校验缺 on-curve 检查**,PDA/token account 可通过 → 转原生 SOL 后无私钥可取。
- **`estimateFees` 的 maxFee 无 base fee 余量**(`baseFees.last + tip`),三档几乎相同,稍涨即卡 mempool 阻塞 nonce。
- **历史记录靠 URL 子串猜网络**(`contains('sepolia')`),自建节点会判错。
- **RPC override 按 Coin 而非按网络存储**,主网 override 会在 Sepolia 会话继续生效。
- **`HistoryScope` 生产中从不挂载**,测试走注入路径、生产走懒构造路径 → 生产装配代码零覆盖。
- **`WalletController` 是 god controller**(414 行 / 4 个领域),任一变更通知全部 5 层作用域。
- **依赖**:`sqlite3_flutter_libs` 上游标记 **EOL**;`go_router` 落后 3 个大版本;`intl: any` 应收紧。
- **提交粒度**:单次 `feat:` 提交达 10,977 行(161 文件),无法 review、无法 bisect。

## 四、已核实为健壮的部分

审计需要平衡——以下项目经针对性攻击性审查后**确认可信**:

**密码学与序列化**
- RLP 编码与黄皮书附录 B 一致,测试用规范原始向量而非自产值
- Keccak-256 经**独立 Python 实现**复算逐字节吻合;EIP-55 对 6 个规范参考地址全部匹配
- EIP-1559 字段序/typed envelope/空 access list/`to=null` 全部正确
- TRON protobuf 字段号与 Tron.proto 一致,测试用**两条真实主网交易**做逐字节复现
- Solana legacy message 的 shortvec 在 6 个规范边界值正确,测试用真实 mainnet-beta 交易复现
- 跨链地址混淆:三种格式两两互拒,已验证

**气隙协议(最强的一块)**
- CBOR 深度上限 16、集合项上限 4096、抗溢出长度校验、拒绝重复 key、拒绝尾随字节、`allowMalformed: false`
- 帧协议 `1 ≤ total ≤ 256`、累计 64KB 上限 fail-closed、CRC 复验
- 过期逻辑抗整数溢出,方向正确(fail closed)
- **未能构造出导致签名器崩溃或越界的输入**
- 秘密无法跨越气隙:线格式**结构上不存在**助记词/熵/私钥字段
- 返回路径三重校验 + secp256k1 恢复签名者 + 常数时间比对

**demo 隔离的正确范式**
- `SIGNED-V1:` 三重门控(生产者/校验器/广播器各自 `kReleaseMode` 拒绝)——**demo 签名不可能到达任何节点**
- `MockCoreCrypto` 生产引导门控正确(`!kReleaseMode && bool.fromEnvironment`),Android 无 wallet-core 时 fail-closed 抛异常
- 摄像头模拟双重门控,fallback 渲染诚实的 "Camera unavailable"

**其他**
- 全仓无硬编码密钥;git 全历史无泄密(唯一助记词命中是 BIP-39 官方测试向量)
- Dart 侧**零日志调用点**,无 analytics/crash SDK → 无泄露路径
- 无深链攻击面(仅 MAIN/LAUNCHER,无 URL scheme,无导出组件)
- Android 内存卫生优秀(entropy 全部 `fill(0)`,正确处理别名)
- 每链错误隔离贯彻:**从不编造数字**,失败即 `--`
- 金额全程 `BigInt`(唯一 double 是 `Balances.fiat` 的显示层)
- drift 迁移只做加表/加可空列,**无数据丢失路径**
- 无 TODO 堆积(产品代码 0 处)、无 skip 测试、无注释掉的测试
- **注释诚实度罕见地高**——几乎每个 fake 都自我标注
