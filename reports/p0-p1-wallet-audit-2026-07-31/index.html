“国际成熟钱包”基线怎么定

本报告没有只比较链和 Token 数量。成熟钱包还应在交易前解释真实资产变化、 识别恶意地址与合约、管理授权，并支持独立签名设备和持续安全运营。官方资料显示：

  • MetaMask 安全提醒 已覆盖信任标记、恶意地址/网站/Token 情报与交易模拟。
  • MetaMask 资产变化预测 会在确认前展示合约交互可能造成的 Token/NFT 变化，并在价格不可用时诚实显示不可用。
  • MetaMask 硬件钱包 支持直连与二维码隔离设备；这类生态兼容度高于 KT Wallet 当前只验证自有 Cold Signer 的状态。
  • MetaMask 授权管理 支持检查和撤销 Token allowance；KT Wallet 已完成五条 EVM 主网的授权扫描、 风险分级与热/观察钱包撤销；生产 Gateway 只读 API 已上线，但尚未完成真实主网撤销验收。
  • OKX Wallet 授权管理 会汇总历史授权并过滤恶意授权投毒；这说明成熟产品的基线还包括持续扫描、 风险运营和历史覆盖，而不仅是能生成一笔撤销交易。
  • GoPlus Token Security API 按 chain id 与完整 Token 合约返回动态风险数据；官方文档标明公共服务限额为 30 次/分钟，因此 Gateway 使用短时缓存且把限流保留为“无法检查”。
  • GoPlus Solana Token Security API 使用独立 Beta endpoint；其官方响应定义 明确区分普通 mint/freeze/metadata 能力与 authority 的 malicious-address 证据。 Gateway 因此只对明确恶意创建者、Hook 或特权 authority 阻止签名，不把 USDC 的合法管理权限误报为恶意。

这些链接只用于校准产品基线，不代表对第三方实现作独立安全背书。
