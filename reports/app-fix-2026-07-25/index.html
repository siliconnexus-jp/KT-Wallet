仍需外部条件的边界

Android 真实 Wallet Core 仍需要 GitHub Packages 凭据。 官方 Android AAR 目前仍要求 GitHub token（read:packages）。默认生产语义构建已改为明确失败关闭，不再自动使用 MockCoreCrypto。此外，仓库内 Android WalletCoreBridge.sign 的逐链私钥注入仍是结构性失败关闭实现；正式处理真实资产前必须完成该实现、固定向量测试和真机验收。
