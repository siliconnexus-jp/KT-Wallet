# test_support

Repository-internal helpers for deterministic KT Wallet tests and security
gates. This package contains no production wallet behavior.

## Public helpers

- `readFixture`, `readJsonFixture`, and `readHexFixture` load package-local test
  vectors.
- `verifyTransitionTable` exhaustively checks allowed and forbidden state
  transitions.
- `dep_check.dart` implements pure checks used by `tool/check_deps.dart` to
  keep KT Cold Signer offline and verify platform backup protections.
- `e2e_credentials.dart` validates disposable real-chain credential batches
  and detects accidental secret disclosure in every public repository text
  artifact, including provider-specific formats and high-entropy values
  assigned to credential fields.

```dart
final report = verifyTransitionTable<State, Event>(
  states: State.values,
  events: Event.values,
  allowed: const [TransitionCase(State.idle, Event.start, State.running)],
  apply: transition,
);
expect(report.problems, isEmpty);
```

Fixtures must never contain funded mnemonics, private keys, signed mainnet
transactions, access tokens, or user data. Network tests inject local secrets
outside Git and reports publish only public addresses and transaction hashes.

`e2e_credentials.dart` does not generate or derive wallet secrets. It validates
the batch ID, UTC lifetime, phrase shape, `0600` file-mode policy and report
redaction boundary around a phrase generated by the native Wallet Core flow.
